# ISUCT Schedule Reborn

Telegram bot for ISUCT university schedule.

## Setup

1. Install dependencies: `bun install`
2. Set environment variables in `.env.local`:
   - `TELEGRAM_BOT_TOKEN` — your bot token from @BotFather
   - `NEXT_PUBLIC_BASE_URL` — your app URL (for production)
3. Run dev server: `bun run dev`
4. Open http://localhost:3000

## Deploy

See the "Подключите своего бота" section at http://localhost:3000#connect
